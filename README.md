# Smart Placement & Skill Tracker

## Overview

Smart Placement & Skill Tracker is a Java based command line application designed to help students prepare for campus placements.

The system allows students to maintain their placement profiles, manage skills, projectt and certifications, analyze placement readiness, identify skill gaps and find suitable company job roles based on eligibility and profile matching.

Placement administrators can manage student records, companies and job roles and generate basic placement statistics and reports.

## Features

### Student Module

- Create student profile
- View student profile
- Update student profile
- Manage skills and proficiency levels
- Manage projects
- Manage certifications
- Check placement readiness
- Find matching companies
- View skill gaps

### Placement Admin Module

- View students
- Search students
- Manage companies
- Manage job roles
- View placement statistics
- Generate reports

## Technology Used

- Java
- Java Collections Framework
- File I/O
- Object-Oriented Programming
- Exception Handling
- Command Line Interface
